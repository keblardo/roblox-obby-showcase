## What it is

A 99-level obby (obstacle course) whose whole map is **generated by code** when the server starts: a lobby, 99
colourful levels with checkpoints and floating level numbers, rest zones with shop stalls every ten levels, a calm
"zen zone" at level 50 and a finish pad that counts completions (completions unlock pets). Between levels 20 and 29 the
course climbs and a "job application" chases you down and kills you on touch.

## What's in this excerpt

| File | What it shows |
|---|---|
| `ObbyBuilder.server.lua` | Builds the lobby, the 99 levels, rest and zen zones and checkpoints. Each level's obstacle is picked with a RNG seeded by the level number, so the course is the same on every server |
| `JobChaser.server.lua` | Per-player chaser that only exists inside its level range, steered every `Heartbeat` |
| `ObstacleHandlers.server.lua` | Spinning bars and disappearing platforms, found through `CollectionService` tags |

Comments are in Spanish.

**Not included on purpose:** the shared config, pets, game passes and shops, client UI scripts and asset IDs.
